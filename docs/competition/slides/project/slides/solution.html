Предлагаемое решение

Документы → проверяемый граф → формальная проверка изменения

1

Извлечь

требования, пределы, материалы и зависимости из PDF, DOCX, XLSX, CSV, TXT и сканов; единицы → СИ

2

Связать

требование → характеристика → компонент → материал; у каждой связи — документ, страница и цитата

3

Проверить

распространить изменение с учётом физики параметра и сравнить новое значение с каждым пределом

Результат: подтверждённое влияние (формальное нарушение), прямое, потенциальное и документарное — с цепочкой и цитатой. Транзитивная связь сама по себе не считается доказательством.

4 · работает полностью локально; LLM подключается опционально, внешние модели — только с разрешения

Решение состоит из трёх шагов. Сначала извлекаем из документов требования и ограничения — по правилам на основе морфологии русского языка, с нормализацией единиц. Затем связываем их в граф, где центральный узел — характеристика: например, «температура среды насосного агрегата». К ней ссылаются требования из всех документов. Наконец, при изменении обходим граф по связям, которые соответствуют физике параметра, и формально сравниваем новое значение с каждым найденным пределом. Важно: система не выдаёт «возможно затронуто» за факт — нарушение подтверждается только формальной проверкой.
