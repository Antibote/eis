Архитектура системы

Модули за интерфейсами: граф, поиск и LLM заменяемы без переписывания алгоритмов

5 · Python: FastAPI, NetworkX, PostgreSQL, pymorphy3, Tesseract, e5-small · React + React Flow · запуск одной командой Docker Compose

Документы разбираются с сохранением координат каждого фрагмента; сканы проходят OCR. Извлечение строит граф знаний, где у каждой связи обязательно есть доказательство: документ, страница, цитата и правило, по которому связь найдена. Над графом работают три модуля: анализ изменений, поиск противоречий и гибридный поиск для помощника. Всё работает локально, без внешних сервисов; LLM подключается через интерфейс и не обязательна.
